# Catering C.H. Pray S.A.S. — Rediseño Web

Rediseño completo de la propuesta web para **Catering C.H. Pray S.A.S.** utilizando la skin y sistema de diseño **«El portacomidas»** (Impeccable Design System).

## 🚀 Demo en vivo
- **Sitio publicado en GitHub Pages**: [https://saimonproduce.github.io/chpray-catering/](https://saimonproduce.github.io/chpray-catering/)

## 🍲 Características principales
- **Materialidad de peltre esmaltado**: Bordes navy clínicos de 2px, broches mecánicos y paleta de colores institucional (salvia hospitalario, maíz tostado, eucalipto frío y punto de tomate).
- **Animaciones fluidas y optimizadas a 60-120 FPS**:
  - Pantalla de carga con ensamble de tazas esmaltadas y salida por GPU.
  - Hero interactivo de portacomidas de 3 niveles con apertura dinámica sin salto de diseño ni reflujo.
  - Rotulado hospitalario en vivo con trazabilidad térmica.
  - Simulador de ahorro en proteínas y calculadora de merma.
  - Termómetros verticales de inocuidad (>65 °C y <4 °C).
  - Asistente en 3 pasos y modal interactivo de cotización/degustación conectado a Google Sheets y WhatsApp.
- **8 subpáginas completas**:
  - `/alimentacion-hospitalaria/`
  - `/catering-corporativo/`
  - `/asados-corporativos/`
  - `/proteinas-al-vacio/`
  - `/guias/`
  - `/guias/proveedor-alimentacion-hospitalaria/`
  - `/guias/costo-catering-corporativo/`
  - `/guias/ahorro-proteinas-porcionadas/`
